ChatGPT-DD Backup

Privacy policy

Effective November 7, 2026.

Access

ChatGPT-DD Backup reads file contents and metadata to back up its owner's designated Google Drive folder. Google authorization grants account-wide read-only access; the configured folder determines the backup's working scope.

Use and storage

Data is used solely for personal backup and restoration. Backups and credentials are stored locally. Google user data is not sold, used for advertising or AI training, or published on this site.

Retention and control

Backups remain until the owner removes them. Source deletions do not remove preserved backups. Access may be revoked through Google Account settings.

This website

This static site receives no backup contents or authorization tokens and includes no analytics scripts. GitHub Pages may process web requests under GitHub's privacy statement.

Google API data

Use and transfer of Google API data will comply with the Google API Services User Data Policy, including its Limited Use requirements.
