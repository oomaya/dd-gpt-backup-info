ChatGPT-DD Backup

Personal backups. Read-only access. Local control.

ChatGPT-DD Backup uses rclone to preserve a designated Google Drive folder on its owner's computer, including exported Google documents. Earlier backups are retained.

The backup connection reads and downloads files. It does not change or delete files in Google Drive.

This site provides application information only. Credentials and backup files stay off this site.
